# Interactive Store product motion

A silent, nine-second HyperFrames composition for the home page. It has three equal three-second scenes: Arc 14 laptop (0–3 s), Pulse headphones (3–6 s), and Haven speaker (6–9 s). Each product is visible from its first frame. The open space at left is reserved for live, accessible HTML text and controls on the page.

The three WebP assets in `assets/` were optimized from the corresponding existing concept images in the repository's main `assets/` directory. No text, pricing, or specifications are baked into the video.

The source is `index.html`; `hyperframes.json` stores the project configuration. HyperFrames `check .` passed with zero errors. The rendered deliverable is copied to the repository's main `assets/home-moments-hyperframes.mp4` (H.264, 1280×720, 30 fps, 9.000 s). Local render artifacts and dependencies are ignored by Git.
